# DSA Problem Recommender

A content-based recommendation system that recommends similar LeetCode problems based on problem titles and topics.

## Features

- Select a LeetCode problem
- Get similar coding problems
- Choose the number of recommendations
- Filter recommendations by difficulty
- View similarity scores
- Interactive Streamlit interface

## Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Streamlit
